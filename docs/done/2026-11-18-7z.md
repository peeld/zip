# 2026-11-18: un7z (.7z)

- New op `un7z` (group `archive`, the shared archive UI): list, view, save
  one, extract all. The status line names the methods, says "solid", and
  says which method stops extraction when one isn't supported.
- `lib/7z.js`: start header, (encoded) header, pack / unpack / substreams
  info, files info (names, empty streams and files, anti items, mtime,
  attributes with the Unix mode). Folders are chains of simple coders: LZMA,
  LZMA2, Deflate (native), Copy, zstd, with BCJ x86 / Delta in front. CRCs
  checked. Symlink targets read at listing when near the start of a folder.
  AES, BCJ2, PPMd, BZip2 and the other filters are refused by name.
- `lib/filters.js`: `deltaFilter` and `x86Filter` moved out of `lib/xz.js`.
  `lib/lzma.js`: `lzmaRaw` (LZMA1 with the properties given) split out of
  `lzmaAlone`.
- Tests: libarchive through ctypes (no CLI needed), `hand7z` for coder
  chains (BCJ + LZMA2, Delta + LZMA1, three folders), damaged / unsupported
  copies, and the 7-Zip command line when installed (CI installs
  p7zip-full). 661 tests pass with p7zip 16.02 installed.
