# 2026-11-21: uniso (ISO 9660 images)

From the Tier 2 list in [../todo/new-ops.md](../todo/new-ops.md). How it
reads them: [../ref/formats.md](../ref/formats.md), "ISO 9660".

- `lib/iso.js` (~330 lines): volume descriptors, Rock Ridge (names, modes,
  symlinks, times, devices / FIFOs, CE, CL / RE relocation, zisofs),
  Joliet, plain ISO 9660; multi-extent files, extended attribute records,
  loops; El Torito and UDF noted on the status line.
- `uniso` op (`archiveOp`); a dropped .iso is routed by content (`CD001` at
  byte 32769, `sniffFile`) or by name.
- Compared by hand: our listing of the Rock Ridge fixture matches 7-Zip's
  apart from the long name (7-Zip uses Joliet, cut to 103 characters), and
  `isoinfo -f` apart from the relocated folders (it lists `rr_moved`).
- Tests: five genisoimage images, a zisofs one (mkzftree) and a hand-built
  one (`hand_iso`); every listed file read back against its source; the op
  in the page. CI now installs genisoimage and zisofs-tools. 1135 pass.
- Left (new-ops.md): UDF, the boot image as `[BOOT]`, multi-session, HFS.
