# 2026-11-08: encode / decode (text encodings)

- New ops `encode` and `decode` on `lib/textenc.js`: base32, base32hex,
  ascii85 (Adobe `<~ ~>`), quoted-printable, URL (`%20`) and form (`+`).
  One command each way with a Format select, not eight commands.
- `core/transform.js`: new `choice` option (a select next to the name). Its
  value goes to `transform` / `outName` / `inspect`; changing it re-runs
  inspect; inspect can set it when a file arrives (decode: `detectEncoding`).
  The select is disabled while running. `style.css`: select styled like inputs.
- decode routes by name: `.b32 .base32 .a85 .ascii85 .qp .urlenc` (registry,
  before `zip`); encode takes any one file while running.
- Tests: base32/base32hex against `basenc` (and `base32 -w 0`), RFC 4648
  vectors; ascii85 against `a85encode(wrapcol=76, adobe=True)` incl. `z`
  groups; qp decoder against `b2a_qp` output (binary and text), our qp
  output checked in Python by `a2b_qp` and `quopri` (lines <= 76, ASCII);
  URL against `quote` / `quote_plus`; error messages; round trips for every
  format with odd chunk sizes; `detectEncoding` on every fixture and on
  plain text; routing; both op mounts (select renames, detect sets the
  select, a wrong pick is rejected and re-checked on change). 428 pass.
