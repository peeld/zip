# 2026-11-08: WebAssembly loading

- Decided how ops load WebAssembly with the site hosted on GitHub Pages
  (only the `<meta>` CSP applies there): add `'wasm-unsafe-eval'` to
  `script-src`, keep `connect-src 'none'`, and ship each `.wasm` as a base64
  JS module. Details and rejected options: `docs/ref/formats.md`,
  "WebAssembly".
- `public/core/wasm.js`: `base64ToBytes`, `compileWasm` (cached per URL, retried
  after a failure), `loadWasm`.
- `tools/wasm2js.py`: `.wasm` -> `.wasm.js` (checks the `\0asm` header and
  records size and sha256 in a comment).
- Tests: `/csp-check.html` (served by `run_tests.py` with index.html's `<meta>`
  CSP) runs `test/wasm-csp.js`. A hand-written `add.wasm` goes through the tool
  and the loader. fetch and eval must stay blocked, and wasm must be blocked
  without the keyword.
- CSP updated in `public/index.html` and `public/.htaccess`. All tests pass.
