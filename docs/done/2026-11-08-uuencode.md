# 2026-11-08: uuencode / uudecode

- New ops `uuencode` (one file -> .uu) and `uudecode` (.uu/.uue, or any file
  whose first line is a `begin` line), on `lib/uu.js`, in the `encode` group.
  - The encoder matches GNU sharutils `uuencode` byte for byte ("`" for zero).
  - `uudecode` opens like an archive (`core/archive.js`): one input can hold
    several `begin … end` blocks, e.g. an email with two attachments, and
    each one is listed by the name in its `begin` line. Reads space or "`"
    for zero, CRLF, stripped trailing spaces, and `begin-base64` blocks.
- `core/archive.js`: new `sizeLabel` option (status line says "decoded"
  instead of "uncompressed").
- `lib/magic.js` `sniffFile`: returns `uu` for a leading `begin` line, so a
  `.txt` holding uuencoded data is routed to `uudecode`.
- Tests: fixtures from `binascii.b2a_uu` (GNU style, space style with CRLF and
  stripped spaces, an email with a uu and a base64 block, cut off, bad
  character, empty file), round trip in 7-byte chunks, error messages with
  line numbers, sniffing, pickOp routing, both op mounts.
